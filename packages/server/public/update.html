Time to update Lookout

If you're on an older version of Lookout, you can update by reading the following. The latest version is 0.4.2.

Download the new version How to update
curl -fsSL https://lookout.hackclub.com/install.sh | sh

Run it in a terminal. It updates Lookout in place, then future versions come with your system updates.

How to update

Update within Lookout

  1. Finish your recording. You can only update when you're on the home page.
  2. Click Restart to Complete Update at the top right of the window once the download finishes.
  3. No button? Quit Lookout with ⌘ Q and open it again. It downloads the update once more and installs it by itself.

Download for Windows Windows on ARM

Run the installer again

  1. Paste this into a terminal.
    curl -fsSL https://lookout.hackclub.com/install.sh | sh
  2. Say yes when it asks. If your copy is from before Lookout had a package repository, it adds one, then updates Lookout in place.
  3. Quit Lookout from the tray icon and open it again.

If your Lookout was installed through a package manager or the command line

Follow these instructions:

sudo apt update && sudo apt upgrade
sudo dnf upgrade
sudo pacman -Syu
